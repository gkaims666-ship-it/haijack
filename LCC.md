# haijack — устройство и правила для агентов

Этот файл читают агенты, когда работают над кодом самого приложения (в том числе при самоулучшении).

## Что это

Терминальный и веб-ассистент разработчика на Node.js (ESM, без внешних зависимостей, Node >= 18.17).
Четыре агента: Architect планирует, Coder пишет, Reviewer проверяет diff, Executor запускает проверки.

## Карта кода

- `bin/lcc.js` — загрузчик: выбирает версию кода (заводская или доработанная), откатывается при сбое.
  При самоулучшении используется только заводской загрузчик — правки этого файла не вступят в силу.
- `src/index.js` — `main(argv, boot)`: аргументы, выбор режима (REPL, `-p`, `--web`). Код возврата 75 — «перезапусти».
- `src/session.js` — команды и запуск задач; общая логика терминала и веба (`/loop`, `/self`, `/clear`…).
- `src/agents/` — `prompts.js` (роли и стандарты), `agent.js` (цикл инструментов), `orchestrator.js` (конвейер и заходы).
- `src/api/` — `anthropic.js`, `openai.js` (локальные модели, адаптер вызовов инструментов, скачивание через Ollama), `huggingface.js` (каталог моделей), `index.js` (выбор клиента).
- `src/tools/` — инструменты агентов: файлы, поиск, команды, загрузка страниц, diff, учёт изменений, проверки.
- `src/self/` — самоулучшение: `store.js` (версии кода), `improve.js` (копия, установка, откат), `check.js` и `check-worker.js` (самопроверка).
- `src/memory.js` — долговременная память и журнал задач.
- `src/web/` — `server.js` (HTTP, настройки), `hub.js` (события, сохранение диалога), `page.js` (весь интерфейс одной страницей).
- `src/ui/` — терминальный интерфейс.
- `test/` — тесты (`node test/run.mjs`), мок-серверы API.

## Правила

- Никаких npm-зависимостей: только встроенные модули Node. Код должен работать в Node 18.17 (Android-сборка) и 22.
- Код обязан работать на Windows, Linux, macOS, в Termux и внутри Android-приложения, где нет отдельного `node`.
- Сообщения для пользователя — на русском, простым языком.
- `src/web/page.js` — содержимое `String.raw`: внутри нельзя писать обратную кавычку и `${`. Скрипт страницы — в стиле ES5.
  Данные от модели и из файлов вставляются только через `textContent`, никогда через `innerHTML`.
- Не ослабляй защиту: подтверждение записи и команд, ручное подтверждение опасных команд, запрет записи вне проекта,
  ключ доступа и проверку Host в веб-сервере.
- Новое поведение покрывай тестом в `test/`. Тесты не ходят в интернет и не трогают настоящий `~/.lcc`
  (первой строкой импортируй `./isolate.js`).
- Версия хранится в двух местах и должна совпадать: `package.json` и `src/version.js`.

## Проверка

- `node test/run.mjs` — все тесты.
- `node test/e2e.mjs node bin/lcc.js` — запуск программы целиком на мок-сервере API.
- Самопроверка версии (`src/self/check.js`) должна проходить: все модули загружаются, веб-сервер поднимается,
  скрипт страницы синтаксически корректен.
