# Инструкции проекта для агентов

Скопируйте этот файл в корень своего проекта как `LCC.md` (подойдёт и `CLAUDE.md` или `AGENTS.md`).
Его содержимое добавляется в системный промт всех агентов.

## Стек
- Python 3.11, FastAPI, pytest

## Команды
- Тесты: `pytest -q`
- Линтер: `ruff check .`

## Правила
- Типизация обязательна, docstring в Google-стиле
- Не трогать папку `legacy/`
